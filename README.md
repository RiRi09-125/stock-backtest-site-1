# 台股策略回測小站（繁體中文版）

## 功能
- 比較買進持有、A1-Q、A1-H、A2、B1、B2 六種策略。
- 顯示期末資產、累積報酬率、年化報酬率、夏普比率、最大回撤、期末現金、手續費與交易次數。
- 顯示每日資產曲線、累積報酬率曲線、期末持股摘要及交易紀錄，並可下載交易紀錄 CSV。
- 使用 Yahoo Finance（yfinance）下載行情。

## 執行方式
1. 安裝 Python 3.10 或更新版本。
2. 在此資料夾開啟終端機並執行：
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```

## 部署
將 `app.py`、`requirements.txt`、`README.md` 上傳到 GitHub 儲存庫，再至 Streamlit Community Cloud 建立 App，主檔路徑填 `app.py`。

## 重要假設與限制
- 初始配置：0050 元大台灣50 70%、中信金 15%、統一 15%。
- 手續費單邊 0.1425%；賣出證交稅簡化採 0050 0.1%、個股 0.3%，未套用券商折扣。
- A1-Q、A1-H、A2、B1、B2 的觸發與交易假設詳見網站介面。
- 不含股利與股利再投資、滑價、完整公司行動及其他實務限制；回測使用開盤價近似成交，整股交易。
- B1/B2 使用移動平均持股成本的 110% 作為觸發線，收盤價回落觸發線以下後重新開放下一次觸發。這些規則是可調整的研究假設，並非投資建議。
- Yahoo Finance 資料可能有缺漏或調整，結果僅供研究與教學示範。
